# Student Life Hub - React Version

## Project Description
A responsive ReactJS web application for students.

## Technologies Used
- ReactJS
- Bootstrap
- React Router
- Vite

## Pages
- Home
- Study
- Events
- Contact

## Setup Instructions

1. Open terminal
2. Run:

npm install

3. Start project:

npm run dev

## Deployment
You can deploy using:
- Vercel
- Netlify
- GitHub Pages
